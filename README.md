# دختر اسنک‌پز 🌽 (SnackPaz Game)

بازی موبایلی مدیریت زمان/آشپزی با برند واقعی «اسنک‌پز» (مهسا، دختر اسنک‌پز، @snackpaz).
وب + PWA + Android (APK/AAB) + iOS.

توسعه‌دهنده: امیراحمد بابائی (amirahmadbabee)

## امکانات
- گیم‌پلی ذرت مکزیکی + کمبو + نذری به بچه‌های کار + دل ❤️
- اکانت کاربری (ایمیل/رمز) + ذخیره‌ی امتیاز + جدول امتیاز آنلاین
- فارسی RTL، اشتراک امتیاز در استوری، دکمه «بیا ببینمغازه!»

## دیپلوی
راهنمای کامل: `DEPLOY.md`

## متغیرهای محیطی
الگو در `.env.example` (یک کپی بساز به `.env` و پر کن):
- `DATABASE_URL`
- `NEXTAUTH_SECRET`
- `NEXTAUTH_URL`
